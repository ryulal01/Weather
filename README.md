# Скрипт работает корректно с включенным vpn
1. Загрузка городов. Сначала ищет локальный файл cities.txt рядом со скриптом(файл должен быть скачан!). Дубликаты убираются через dict.fromkeys() (сохраняет порядок).
2. API-запросы. Для каждого города обращается к https://wttr.in/{City}?format=j1, где j1 — это JSON-формат. В ответе температура лежит в current_condition[0].temp_C, страна — в nearest_area[0].country[0].value. Город кодируется через urllib.parse.quote, чтобы кириллица и пробелы не ломали URL.
3. Модель WeatherData. Dataclass с тремя обязательными полями: город, температура в °C, страна.
4. Вывод по городам — в формате Tokyo, Japan +18 °C.
5. Группировка по странам через defaultdict(list) и вывод в формате Japan — 3 cities, avg: +19 °C, min: +16 °C, max: +22 °C.
